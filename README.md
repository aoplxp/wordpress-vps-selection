## WordPress 建站 VPS 到底在选什么

很多人以为是在比价格，其实是在比三件事。

**内存决定你能不能装得下。** WordPress 本体不占什么，占内存的是 PHP-FPM 进程、MySQL、缓存插件、以及 WooCommerce 那套东西。LNMP（Linux + Nginx + MySQL + PHP）比 Apache 省内存，1GB 的机器跑起来有空间，但空间不多。有个细节常被忽略：1GB 内存装 MySQL 8.0 容易直接崩，选 MySQL 5.7 或 MariaDB 10 才稳，跑 WordPress 完全够用。

**线路决定你后台的体感。** 同样一台机器，晚高峰打开后台要 3 秒还是 0.8 秒，跟配置无关，跟线路有关。普通国际线路进了国内骨干网就开始挤，CN2 GIA、AS9929、AS4837 这类优化线路才谈得上稳定。

**维护方式决定你后面累不累。** 市面上叫“WordPress VPS”的产品分两种：一种是把 OpenLiteSpeed、LSCache、PHP 都调好、开机就能登录后台的预配置机型；另一种是给你一台干净的 KVM 机器加 root 密码，环境自己装。价格能差十倍，因为卖的根本不是同一种东西。

## 配置怎么定：内存、MySQL 版本和面板选择

内存这一项，我的判断是：**1G 是“能上路”，2G 是“开着舒服”，4G 是“能拉货”**。这不是拍脑袋，差异来自软件栈的固定开销——Nginx 加 PHP-FPM 加 MySQL 的基础占用就吃掉几百兆，剩下给 WordPress 和插件的空间在 1G 机器上只剩两三百兆，一个内存泄漏的插件就能让你看到 502。

MySQL 版本这件事必须单独提醒：**1G 内存不要装 MySQL 8.0**。8.0 默认配置对内存的胃口比 5.7 大得多，在 1G 机器上很容易启动失败或者跑着跑着被 OOM 杀掉。安装 LNMP 时选 MySQL 5.7 或 MariaDB 10，WordPress 的所有功能都不受影响。

面板还是纯命令行，取决于你愿不愿意花两小时学命令。

宝塔面板这类图形工具确实友好，装完打开浏览器就能点着建站、建库、传文件、申请证书。代价是它自己要吃内存。**1G 机器上同时跑面板和 WordPress 会非常紧，2G 以上用面板才合理**。如果你买的是 68 元那款，老老实实用 LNMP 命令行更省资源，装完之后内存占用能低一大截。

## 从空机器到 WordPress 跑起来：典型 LNMP 流程

以下是通用的 LNMP 建站路径，所有 KVM 架构的 Linux VPS 都适用。丽萨主机的机器同样是给 root 密码、自己 SSH 登录，流程一致。

**第一步，SSH 登录。** 独立 IP 的机器直接 `ssh root@你的IP`；如果是 NAT 机型，需要先在面板把 22 端口映射出去，再用 `ssh -p 映射端口 root@你的IP`。登录后先 `passwd` 改掉初始密码。

**第二步，开 screen 再装环境。** 这一步是新手最容易翻车的地方：LNMP 编译安装要 20 到 40 分钟，中途 SSH 断线，安装进程就跟着断了。先执行 `screen -S lnmp`，断线后重连执行 `screen -r lnmp` 就能回到原来的窗口。

**第三步，装 LNMP。** 用 lnmp.org 的一键包，交互选项里 MySQL 选 5.7 或 MariaDB，PHP 选 7.4 以上，其余不知道选什么就一路回车。装完执行 `lnmp status`，确认 Nginx、MySQL、PHP-FPM 三个都是 running。

**第四步，域名解析。** 域名 A 记录指向 VPS 的 IP。别急着往下走，等解析生效——用 ping 或者在线 DNS 查询确认指向对了，否则 WordPress 装完写进数据库的地址是错的，后面要改很麻烦。

**第五步，添加站点。** 执行 `lnmp vhost add`，输入域名，网站目录用默认的 `/home/wwwroot/你的域名`，SSL 选 Let's Encrypt 免费证书，**伪静态规则一定选 WordPress**。这一步选错，后面文章链接全是 404。

**第六步，建数据库。** 登录 MySQL 后执行：

sql
CREATE DATABASE wordpress_db DEFAULT CHARSET utf8mb4;
CREATE USER 'wp_user'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON wordpress_db.* TO 'wp_user'@'localhost';
FLUSH PRIVILEGES;


库名、用户名、密码自己定，记下来，装 WordPress 时要填。LNMP 装完后 MySQL 的 root 密码存在 `/root/lnmp_soft/mysql_root_password` 里，忘了就 cat 一下。

**第七步，放 WordPress 文件。** 进网站目录，`wget https://wordpress.org/latest.tar.gz`，然后 `tar -xzf latest.tar.gz --strip-components=1` 直接解压到当前目录，删掉压缩包。接着改权限：`chown -R www:www` 加 `chmod -R 755`，属主不对后台会报各种奇怪的错。

**第八步，浏览器安装。** 打开域名，跟着向导填数据库信息、站点标题、管理员账号。装完进 `你的域名/wp-admin`，第一件事是去「设置 → 固定链接」选“文章名”然后保存一次，让伪静态规则生效。

整条链路里，最容易卡住的是三个点：解析没生效就装、忘了开 WordPress 伪静态、目录权限没改。这三处都过了，剩下的就是内容和插件的事。

## 便宜背后的限制，以及哪些人不该买

**它是自管机器，不是托管服务。** 丽萨主机给你的是 KVM 机器和 root 权限，操作系统、Web 环境、数据库、备份策略全在你自己手上。官方帮助中心提供 SSH 连接这类文档，但不会帮你调 PHP 参数或者排查插件冲突。完全不想碰命令行的人，买这类产品的体验会很差——出问题时没有“帮你处理一下”的选项。

**新加坡节点不是为大陆访问优化的。** 官方在产品页写得很直白：非中国大陆直连优化网络，联通和部分地区移动直连效果不错，建议通过香港或日本线路中转使用。如果你的读者主要在国内，用新加坡 BGP 节点做源站，体感不会好。要么选香港、日本这类离得近的节点，要么给站点套一层 CDN。

**硬盘起步只有 10G。** 这个容量装 WordPress 加几个插件没问题，但原图、备份、日志很快就会把它填满。规划站点时就把“图片放对象存储”写进方案，比事后迁移省事。

**流量有月度上限，超了要处理。** 6000GB、2000GB、600GB 这些数字对不同站点意义完全不同：纯文字博客几年都用不完，图片站一个月就能见底。不限流量的机型价格明显更高，值不值取决于你的实际用量。下单前把超出流量后的处理方式在条款里看清楚。

**境外机房走不了国内 ICP 备案。** 服务器在新加坡、美国、香港等地，备案需要境内接入商，这条路线本身就不适用。如果网站必须备案，得换方向。

**退款是 48 小时。** 套餐页对每一款都标注了“48 小时不满意，无条件退款”。这个窗口足够你装好环境、跑一遍压力测试、确认线路体感，但不够你慢慢验证一个月的稳定性。买之前想清楚，别把试用期当考察期。

**结算页留意优惠码。** 官网下单流程里有优惠码输入框，当前是否有活动、能不能和年付折扣叠加，以结算页实际显示为准。

**谁不适合买：** 想要“付钱就能登录 WordPress 后台”的人；站点一上线就要扛高并发的人；需要有人帮你做数据库调优、缓存配置、安全加固的人；网站必须备案的人。这几类需求，要么选预配置的 WordPress 托管产品，要么选带托管支持的方案，价格会高一个量级，但省下的是你的时间。

## 常见问题

**1G 内存到底能不能跑 WordPress？**
能。LNMP 比 Apache 省内存，1G 机器跑单站点、插件控制在十个以内、不开重型页面构建器，是够用的。要避开的坑是 MySQL 8.0——它在 1G 机器上很容易把内存吃干。选 MySQL 5.7 或 MariaDB 10，稳定性会好很多。

**装宝塔还是用 LNMP 命令行？**
